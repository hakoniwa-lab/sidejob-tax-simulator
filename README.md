# 副業の税金シミュレーター MVP

本業の年収・副業の収入と経費を入力するだけで、副業によって増える所得税・住民税の目安と確定申告の要否を計算するWebアプリ。HAKONIWA LAB([[takehome-calculator]]・[[furusato-simulator]]・[[retirement-simulator]]と同じ計算機型)の8本目のツール。[[sidejob-checker]]で向いている副業ジャンルが分かった後の「実際いくら税金がかかるか」という自然な次のステップとして企画。

## ローカルでの動作確認

```
cd sidejob-tax-simulator
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。`index.html` を直接ダブルクリックしても動作する(外部通信は一切行わない)。

## ファイル構成

```
sidejob-tax-simulator/
├─ index.html          … 入力フォーム+結果表示のSPA本体
├─ css/style.css        … 他アプリと同じCSS変数デザインシステム(コピー)
└─ js/
    ├─ calculate.js       … 副業による追加税額の計算ロジック(純粋関数、DOM非依存)
    └─ app.js             … フォームの入力受付・DOM描画
```

## 計算ロジックについて

「副業を始めたことで、本業だけの場合と比べていくら税金が増えるか」を算出する設計(`js/calculate.js`の`calcSidejobTax`)。給与所得控除・所得税率表はtakehome-calculator/furusato-simulator/retirement-simulatorと共通のロジック。

1. **給与のみの税額**(比較のベースライン)と**給与+副業を合算した税額**をそれぞれ計算し、その差分を「副業により増える税額」とする(所得税・住民税それぞれ)。この設計により、単に副業所得に一律の税率を掛けるより正確な、限界税率を反映した増分を算出できる。
2. **副業所得**は雑所得(会社員の副業として最も一般的なケース)を想定し、副業収入から必要経費を引いた金額。事業所得として青色申告する場合(青色申告特別控除等)は結果が異なる旨をREADME・アプリ内注記に明記。
3. **確定申告要否の目安**: 副業所得(雑所得等)が年間20万円を超える場合、原則として所得税の確定申告が必要という、いわゆる「20万円ルール」を判定して表示。20万円以下でも住民税の申告は別途必要な場合がある旨も明記。

### 検証(2026-08-02)

- 給与500万円・副業所得40万円(収入50万円−経費10万円) → 追加所得税約5.9万円、追加住民税4万円、副業手取り約30.1万円
- 給与400万円・副業所得15万円(20万円以下) → 確定申告不要の判定が正しく機能、追加税額込みで手取り約12万円

いずれも手計算での検算と一致(端数処理による1円未満の誤差は許容)。

**注意**: 本シミュレーターは一般的な会社員の雑所得としての副業を想定した概算。事業所得としての青色申告、配偶者控除・社会保険料控除等の他の所得控除がある場合は結果が異なる。年度が変わったら所得税率表を再確認すること。
